## 症状

Windowsのターミナルで以下のようなエラーが出てnpmが動かない。

```
'npm' は、内部コマンドまたは外部コマンド、
操作可能なプログラムまたはバッチ ファイルとして認識されていません。
```

または

```
npm : このシステムではスクリプトの実行が無効になっているため
```

## 環境

- Windows 10 / 11
- Node.js
- PowerShell / コマンドプロンプト

## 原因と解決方法

### 原因1：Node.jsがインストールされていない

#### 確認方法

```
node -v
npm -v
```

コマンドが認識されない場合はNode.jsが入っていない。

#### 解決方法

1. https://nodejs.org にアクセス
2. LTS版をダウンロードしてインストール
3. ターミナルを再起動して再確認

### 原因2：環境変数のPATHが通っていない

Node.jsをインストールしてもnpmが動かない場合はPATHの問題。

#### 確認方法

```
where npm
```

パスが表示されない場合はPATHが通っていない。

#### 解決方法

1. Windowsの検索で「環境変数」を検索
2. 「システム環境変数の編集」を開く
3. 「環境変数」ボタンをクリック
4. 「Path」を選択して「編集」
5. Node.jsのインストールパスを追加（例：C:\Program Files\nodejs\）
6. OKで閉じてターミナルを再起動

### 原因3：PowerShellのスクリプト実行ポリシーが制限されている

以下のエラーが出る場合。

```
このシステムではスクリプトの実行が無効になっているため
ファイル npm.ps1 を読み込むことができません。
```

#### 解決方法

PowerShellを管理者として実行して以下を実行。

```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

確認が求められたら「Y」を入力。

### 原因4：ターミナルを再起動していない

インストール後にターミナルを再起動しないと設定が反映されない。
必ずターミナルを閉じて開き直す。

## ハマったポイント

- Node.jsをインストールしてもターミナルを再起動しないと認識されない
- PowerShellとコマンドプロンプトで挙動が違う場合がある
- 管理者権限でターミナルを起動すると解決することがある

## 確認コマンド

最終的に以下が表示されれば正常。

```
node -v
v22.0.0（バージョンが表示される）

npm -v
10.0.0（バージョンが表示される）
```
